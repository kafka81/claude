# Claude Code 
Desenvolva o JARVIS, meu assistente pessoal de inteligência artificial, como uma aplicação WEB multiplataforma (PWA).

IMPORTANTE: NÃO QUERO APK, NÃO QUERO EXIGIR INSTALAÇÃO DE APLICATIVO E NÃO QUERO DEPENDER DA PLAY STORE.

Quero acessar o JARVIS pelo navegador Google Chrome, tanto no Android quanto no Windows 11.

Compatibilidade

- Android pelo Chrome.
- Windows 11 pelo Chrome ou Edge.
- Interface responsiva para celular e computador.
- Possibilidade de adicionar à tela inicial do celular.
- Sincronização pela internet, mesmo em redes diferentes.

Funcionalidades

- Conversar com inteligência artificial.
- Reconhecimento de voz.
- Respostas com voz masculina em português brasileiro.
- Palavra de ativação JARVIS, quando suportada.
- Histórico de conversas.
- Memória configurável.
- Pesquisa na internet.
- Interface futurista.

Controle remoto

Quero enviar comandos do celular para meu computador Windows 11 pela internet.

Exemplos:

- Abrir programas.
- Abrir sites.
- Consultar status do PC.
- Executar ações autorizadas.

Crie um agente seguro para Windows que se conecte ao servidor na nuvem. O navegador não deve receber acesso irrestrito ao computador.

Tecnologias

- Frontend: React ou Next.js.
- PWA: funcionamento instalável pelo navegador.
- Backend: Python com FastAPI.
- Banco de dados: PostgreSQL.
- Comunicação: WebSocket e HTTPS.
- Inteligência artificial através de API.

Design

Crie uma interface inspirada no JARVIS do Homem de Ferro:

- Fundo escuro.
- Azul e ciano.
- Círculo holográfico animado.
- Indicador de voz.
- Animações futuristas.
- Interface adaptável para celular e computador.

Entrega

Quero o projeto completo, com código funcional, estrutura de arquivos, instruções de hospedagem e publicação.

Entregue um endereço HTTPS para acessar o JARVIS pelo celular e computador quando o projeto estiver hospedado.
